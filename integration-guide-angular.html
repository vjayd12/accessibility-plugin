DWAO Accessibility Widget
Angular Integration Guide

Integration Guide — v1.0.0

This guide explains how to integrate the DWAO Accessibility Widget (acc.js) into an Angular application. The widget adds a fully featured accessibility panel to your site — text size, contrast, dyslexia font, reading line, cursor size, and more. It has no npm dependencies and requires no build-step changes.

Files Required

File Purpose
acc.js The widget script — place it in public/ (Angular 17+) or src/assets/ (Angular 16 and below). No angular.json changes are needed in either case.
dwao-accessibility.d.ts TypeScript declaration file — augments Window with the DWAOAccessibility global. Angular projects always use TypeScript, so this file is required.

Integration Steps

1Add the Toggle Button to src/index.html

In your project's src/index.html, add the following markup inside <body>, just before </body>:

<div class="accessibility-div">
  <button id="accessibilityToggleBtn"></button>
</div>
The widget automatically populates the button with an icon and label. Do not put any text inside the button manually.

2Load the Script in src/index.html

Add the script tag after the button div, before </body>:

<!-- Angular 17+ (new application builder — public/ folder) -->
<script src="acc.js"></script>

<!-- Angular 16 and below (webpack builder — src/assets/ folder) -->
<script src="assets/acc.js"></script>

Available data-* configuration attributes (all optional):

Attribute Values Default Description
data-position bottom-left, bottom-right, top-left, top-right bottom-left Position of the toggle button
data-theme purple, blue, green purple Widget color theme
data-brand-color Any hex color e.g. #e63946 — Overrides the theme color with a custom brand color
data-lang en en Widget UI language

Your complete src/index.html should look like this:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>Your App</title>
</head>
<body>
  <app-root></app-root>

  <div class="accessibility-div">
    <button id="accessibilityToggleBtn"></button>
  </div>
  <!-- Angular 17+: file goes in public/acc.js -->
  <script src="acc.js" data-position="bottom-left" data-theme="purple"></script>

  <!-- Angular 16 and below: file goes in src/assets/acc.js -->
  <!-- <script src="assets/acc.js" data-position="bottom-left" data-theme="purple"></script> -->
</body>
</html>
Angular 17+ uses the new application builder — place acc.js in public/ and reference it as src="acc.js". No angular.json changes needed.

Angular 16 and below uses the webpack builder — place acc.js in src/assets/ and reference it as src="assets/acc.js". No angular.json changes needed.

3Add TypeScript Types

Copy dwao-accessibility.d.ts into your src/ folder. No import is needed — the declare global block automatically augments the Window interface project-wide, so window.DWAOAccessibility is fully typed everywhere in the project. 

// dwao-accessibility.d.ts — copy to src/
declare global {
  interface Window {
    DWAOAccessibility?: {
      version: string;
      reset: () => void;
      reinit: () => void;
    };
  }
}
export {};
If you prefer not to copy the file, you can use an inline cast wherever needed:
(window as any).DWAOAccessibility?.reinit()

4Reinitialize on Route Changes

Angular Router navigates between views without a full browser reload. The widget must be told to re-scan the DOM after each navigation to work correctly on new pages.

In your src/app/app.component.ts, inject Router and listen for NavigationEnd events:

// src/app/app.component.ts
import { Component, OnInit } from '@angular/core';
import { Router, RouterOutlet, NavigationEnd } from '@angular/router';
import { filter } from 'rxjs/operators';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [RouterOutlet],
  templateUrl: './app.component.html',
  styleUrl: './app.component.css',
})
export class AppComponent implements OnInit {
  constructor(private router: Router) {}

  ngOnInit() {
    this.router.events
      .pipe(filter((e) => e instanceof NavigationEnd))
      .subscribe(() => {
        requestIdleCallback(() => {
          window.DWAOAccessibility?.reinit();
        });
      });
  }
}

Where Changes Are Required — Summary

File Change Required
public/acc.js (Angular 17+)
src/assets/acc.js (Angular 16 and below)		 Place the widget script in the correct folder for your Angular version — no angular.json changes needed in either case
src/index.html Add the <div class="accessibility-div"> button markup
src/index.html Add the <script src="assets/acc.js" ...> tag with config attributes
src/dwao-accessibility.d.ts Copy from the kit — TypeScript type declaration for window.DWAOAccessibility

Note

The button id="accessibilityToggleBtn" must be unique on the page. Do not duplicate it.
