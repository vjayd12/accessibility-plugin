DWAO Accessibility Widget
React Integration Guide

Integration Guide — v1.0.0

This guide explains how to integrate the DWAO Accessibility Widget (acc.js) into a React application. The widget adds a fully featured accessibility panel to your site — text size, contrast, dyslexia font, reading line, cursor size, and more. It has no npm dependencies and requires no build-step changes.

Files Required

File Purpose
acc.js The widget script — host it in your project's public/ folder and reference it in index.html
dwao-accessibility.d.ts TypeScript declaration file — augments Window with the DWAOAccessibility global. Required for TypeScript projects; optional for plain JavaScript.

Project Structure — Files to Add or Modify

public/
  acc.js                              ← widget script (static asset)

src/
  dwao-accessibility.d.ts            ← TypeScript types (TypeScript projects only)

Integration Steps

1Add the Toggle Button to index.html

In your project's index.html, add the following markup inside <body>, just before </body>:

<div class="accessibility-div">
  <button id="accessibilityToggleBtn"></button>
</div>
The widget automatically populates the button with an icon and label. Do not put any text inside the button manually.

2Load the Script in index.html

Add the script tag after the button div, before </body>:

<script src="acc.js" ></script>

Available data-* configuration attributes (all optional):

Attribute Values Default Description
data-position bottom-left, bottom-right, top-left, top-right bottom-left Position of the toggle button
data-theme purple, blue, green purple Widget color theme
data-brand-color Any hex color e.g. #e63946 — Overrides the theme color with a custom brand color
data-lang en en Widget UI language

Your complete index.html should look like this:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>Your App</title>
</head>
<body>
  <div id="root"></div>

  <div class="accessibility-div">
    <button id="accessibilityToggleBtn"></button>
  </div>
  <script src="/public/acc.js" data-position="bottom-left" data-theme="pnb"></script>
</body>
</html>
Note :- Calling of accessibility file depends on project strucutre it may defer from project to project so link the file according to you project strucutre.

3Add TypeScript Types (TypeScript projects only)

Copy dwao-accessibility.d.ts into your src/ folder (or any directory covered by your tsconfig.json include paths). No import is needed — the declare global block automatically augments the Window interface project-wide, so window.DWAOAccessibility is fully typed everywhere. 

// dwao-accessibility.d.ts — copy to src/
declare global {
  interface Window {
    DWAOAccessibility: {
      version: string;
      reset: () => void;
      reinit: () => void;
    };
  }
}
export {};
If you prefer not to copy the file, you can add an inline cast in your component instead:
(window as any).DWAOAccessibility?.reinit()

4Reinitialize on Route Changes

React Router replaces page content without a full browser reload. The widget must be told to re-scan the DOM after each navigation to work correctly on new pages.

Create a new file src/components/AccessibilityReinit.jsx (or .tsx for TypeScript):

// src/components/AccessibilityReinit.jsx (or .tsx)
import { useEffect } from "react";
import { useLocation } from "react-router-dom";

export default function AccessibilityReinit() {
  const location = useLocation();

  useEffect(() => {
    requestIdleCallback(() => {
      if (window.DWAOAccessibility) window.DWAOAccessibility.reinit();
    });
  }, [location.pathname]);

  return null;
}

Then render it inside <BrowserRouter> in your root src/App.jsx:

// src/App.jsx
import { BrowserRouter, Routes, Route } from "react-router-dom";
import AccessibilityReinit from "./components/AccessibilityReinit";

export default function App() {
  return (
    <BrowserRouter>
      <AccessibilityReinit />
      {/* your routes */}
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
}

Where Changes Are Required — Summary

File Change Required
index.html Add the <div class="accessibility-div"> button markup
index.html Add the <script src="acc.js" ...> tag with config attributes
src/dwao-accessibility.d.ts Copy from the kit — TypeScript type declaration for window.DWAOAccessibility (TypeScript projects only)
src/components/AccessibilityReinit.jsx / .tsx Create this new component (see Step 4)
src/App.jsx / .tsx Import and render <AccessibilityReinit /> inside <BrowserRouter>

Note:-

The button id="accessibilityToggleBtn" must be unique on the page. Do not duplicate it.
