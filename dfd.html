DWAO Accessibility Widget v2.0.0

Architecture & Security Review — dwao-a11y-widget.js · 2248 lines · Zero dependencies

Architecture Layers
Layer 1
Vanilla JS & CSS
  • IIFE wrapper — no global leakage
  • Read data-* attrs from <script> tag
  • Resolve theme / brand color → BRAND
  • Inject CSS into <head>
  • Apply position variant CSS
Layer 2
Data & State
  • Inline SVG icon map (ICONS{})
  • Section / card config (accessibilitySections[])
  • Feature dispatch map (optionActions{})
  • Module-level closure state flags
  • CSS class name arrays (font, line, letter, align)
Layer 3
UI Construction
  • createEl() DOM utility
  • svgIcon() icon builder
  • createOptionCard() — 24 feature cards
  • createAccordionSection() — 4 sections
  • buildAccessibilityPanel()
  • buildScreenReaderPanel()
Layer 4
Feature Engine
  • Typography (font size, letter/line spacing, align, dyslexia)
  • Visual / Color (contrast, invert, grayscale, saturation)
  • Navigation (cursor, links, buttons, skip link, reading line)
  • Screen Reader (Web Speech API — hover-to-speak)
  • Text Magnifier (floating lens overlay)
  • Media Control (audio/video/YouTube/GIF pause)
  • Page Structure (heading nav panel)
  • Virtual Keyboard (draggable, injects into active input)
Layer 5
Event & Interaction
  • Accordion expand/collapse
  • Card click → optionActions dispatch
  • Keyboard nav (↑↓ Arrow, Enter, Space, Escape)
  • Click-outside to close panel
  • ARIA live region announcements
  • Auto-label unlabelled form fields
  • Reset All → resetAllAccessibility()
Layer 6
Persistence
  • Key: accessibility_local_settings
  • Value: JSON array of active datakey strings
  • Write: on every card click (via requestIdleCallback)
  • Read: on init — replays clicks to restore state
  • Clear: on Reset All
Public API
window.DWAOAccessibility
  • .version — "2.0.0"
  • .reset() — programmatic reset all
  • Everything else stays inside IIFE closure
