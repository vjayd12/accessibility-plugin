DWAO Accessibility Widget

Integration Guide — v1.0.0

What's in the Package

dwao-a11y-kit/

  dwao-a11y-widget.js ← The widget script (add this to your project)

  INTEGRATION-GUIDE.html ← This document

Zero dependencies. The widget is a single JavaScript file with all icons embedded inline. No external images, CSS files, or API calls required.

Quick Start (2 Minutes)

1

Copy the script into your project

Place dwao-a11y-widget.js in your project's scripts or assets folder. For example:

your-website/

  js/

    dwao-a11y-widget.js

  index.html

2

Add the accessibility button container

Place this HTML where you want the accessibility button to appear (typically in your header/navbar or anywhere on the page):

<!-- Accessibility widget container -->

<div class="accessibility-div">

  <button id="accessibilityToggleBtn"

          aria-label="Open accessibility options"

          title="Accessibility">

    <!-- The widget auto-inserts the icon here -->

  </button>

</div>

3

Add the script tag

Place this before the closing </body> tag:

<script src="js/dwao-a11y-widget.js"></script>

That's it! The widget will automatically initialise when the page loads. Click the accessibility button to open the panel.

Configuration Options

Customise the widget using data-* attributes on the script tag:

<script

  src="js/dwao-a11y-widget.js"

  data-position="bottom-right"

  data-theme="custom"

  data-brand-color="#E91E63"

  data-lang="en"

></script>

CMS-Specific Instructions

WordPress

Upload dwao-a11y-widget.js to your theme's js/ folder, then add to your theme's footer.php (or use a plugin like "Insert Headers and Footers"):

<!-- Before </body> in footer.php -->

<div class="accessibility-div">

  <button id="accessibilityToggleBtn"

          aria-label="Accessibility"></button>

</div>

<script src="<?php echo get_template_directory_uri(); ?>/js/dwao-a11y-widget.js"></script>

Shopify

Upload to Assets in your theme, then add to theme.liquid before </body>:

<div class="accessibility-div">

  <button id="accessibilityToggleBtn"></button>

</div>

<script src="{{ 'dwao-a11y-widget.js' | asset_url }}"></script>

Adobe Experience Manager (AEM)

Add the script to a clientlib or as an Experience Fragment in your page template. Place the button HTML in your header component.

React / Next.js / Single-Page Apps

// In your layout component or _app.js

import { useEffect } from 'react';


export default function Layout({ children }) {

  useEffect(() => {

    // Create the trigger button

    const container = document.createElement('div');

    container.className = 'accessibility-div';

    container.innerHTML = '<button id="accessibilityToggleBtn" aria-label="Accessibility"></button>';

    document.body.appendChild(container);


    // Load the widget

    const script = document.createElement('script');

    script.src = '/js/dwao-a11y-widget.js';

    document.body.appendChild(script);


    return () => {

      script.remove();

      container.remove();

    };

  }, []);


  return <>{children}</>;

}

Styling the Trigger Button

The widget automatically inserts an accessibility icon into your button. You can style the button however you like:

/* Example: make it a floating circle */

#accessibilityToggleBtn {

  position: fixed;

  bottom: 20px;

  right: 20px;

  width: 48px;

  height: 48px;

  border-radius: 50%;

  background: #6C3FC5;

  border: none;

  cursor: pointer;

  box-shadow: 0 2px 12px rgba(0,0,0,0.2);

  z-index: 9998;

  padding: 10px;

}

#accessibilityToggleBtn img,

#accessibilityToggleBtn svg {

  width: 100%;

  height: 100%;

  filter: brightness(0) invert(1); /* white icon */

}

Note: If you prefer the widget to handle button positioning automatically, simply set data-position on the script tag and the widget will position the button for you.

Troubleshooting

Widget not appearing? Check these common issues:

1. Missing container: Make sure you have <div class="accessibility-div"> with a <button id="accessibilityToggleBtn"> inside it on the page.

2. Script path: Verify the src in your script tag points to the correct location of dwao-a11y-widget.js.

3. Script loading order: The script should be placed before </body> so the DOM is ready when it runs.

4. CSS conflicts: If your site's CSS overrides the widget panel styles, the widget uses .accessibility-panel as its main container. You can increase specificity if needed.

5. Content Security Policy (CSP): If your site uses a strict CSP, ensure 'unsafe-inline' is allowed for styles (the widget injects its own CSS):

style-src 'self' 'unsafe-inline';

font-src 'self' https://cdn.jsdelivr.net; /* for OpenDyslexic font */

JavaScript API

The widget exposes a minimal API on window.DWAOAccessibility:

// Get the widget version

console.log(window.DWAOAccessibility.version); // "1.0.0"


// Reset all accessibility settings to default

window.DWAOAccessibility.reset();
