# DWAO Accessibility Widget Suite

All DWAO Accessibility Widget kits in one branch, one folder per kit.

| Folder | Kit | Source branch |
|---|---|---|
| [`react/`](react/) | React kit (includes the PNB portal fixes) | `accessibility-fixes-pnb` |
| [`angular/`](angular/) | Angular kit | `angular` |
| [`vanilla-js/`](vanilla-js/) | Vanilla JS kit | `vanila-js` |
| [`jsp/`](jsp/) | JSP kit and example project | `jsp` |
| [`chrome-extension/`](chrome-extension/) | Chrome extension | `chrome-extension` |

Each folder keeps the full commit history of its source branch.
