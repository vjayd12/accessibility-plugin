DWAO Accessibility Widget
Vue Integration Guide

Integration Guide — v1.0.0

This guide explains how to integrate the DWAO Accessibility Widget (acc.js) into a Vue application. The widget adds a fully featured accessibility panel to your site — text size, contrast, dyslexia font, reading line, cursor size, and more. It has no npm dependencies and requires no build-step changes.

Files Required

File Purpose
acc.js The widget script — place it in your project's public/ folder (Vue CLI or Vite) and reference it in index.html
dwao-accessibility.d.ts TypeScript declaration file — augments Window with the DWAOAccessibility global. Required for TypeScript projects; optional for plain JavaScript.

Project Structure — Files to Add or Modify

public/
  acc.js                            ← widget script (Vue CLI / Vite serve public/ automatically)

src/
  dwao-accessibility.d.ts           ← TypeScript types (TypeScript projects only)
  main.js / main.ts                 ← add router.afterEach reinit here

Integration Steps

1Add the Toggle Button to index.html

For Vue CLI, edit public/index.html.
For Vite, edit index.html at the project root.

Add the following markup inside <body>, just before </body>:

<div class="accessibility-div">
  <button id="accessibilityToggleBtn"></button>
</div>
The widget automatically populates the button with an icon and label. Do not put any text inside the button manually.

2Load the Script in index.html

Add the script tag after the button div, before </body>:

<!-- Vue CLI -->
<script src="<%= BASE_URL %>acc.js"></script>

<!-- Vite -->
<script src="/acc.js"></script>

Available data-* configuration attributes (all optional):

Attribute Values Default Description
data-position bottom-left, bottom-right, top-left, top-right bottom-left Position of the toggle button
data-theme purple, blue, green purple Widget color theme
data-brand-color Any hex color e.g. #e63946 — Overrides the theme color with a custom brand color
data-lang en en Widget UI language

Your complete index.html should look like this:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>Your App</title>
</head>
<body>
  <div id="app"></div>

  <div class="accessibility-div">
    <button id="accessibilityToggleBtn"></button>
  </div>

  <!-- Vue CLI -->
  <script src="<%= BASE_URL %>acc.js" data-position="bottom-left" data-theme="purple"></script>

  <!-- Vite (use this instead) -->
  <!-- <script src="/acc.js" data-position="bottom-left" data-theme="purple"></script> -->
</body>
</html>
Note: Calling of accessibility file depends on project structure — it may differ from project to project, so link the file according to your project structure.

3Add TypeScript Types (TypeScript projects only)

Copy dwao-accessibility.d.ts into your src/ folder (or any directory covered by your tsconfig.json include paths). No import is needed — the declare global block automatically augments the Window interface project-wide, so window.DWAOAccessibility is fully typed everywhere. 

// dwao-accessibility.d.ts — copy to src/
declare global {
  interface Window {
    DWAOAccessibility: {
      version: string;
      reset: () => void;
      reinit: () => void;
    };
  }
}
export {};
If you prefer not to copy the file, you can add an inline cast wherever needed:
(window as any).DWAOAccessibility?.reinit()

4Reinitialize on Route Changes

Vue Router navigates between views without a full browser reload. The widget must be told to re-scan the DOM after each navigation to work correctly on new pages.

In your src/main.js (or main.ts), use the router.afterEach hook after the router is registered:

// src/main.js (or main.ts)
import { createApp } from 'vue';
import App from './App.vue';
import router from './router';

const app = createApp(App);
app.use(router);
app.mount('#app');

router.afterEach(() => {
  requestIdleCallback(() => {
    if (window.DWAOAccessibility) window.DWAOAccessibility.reinit();
  });
});
router.afterEach fires after every navigation is confirmed. Placing the hook in main.js after app.use(router) ensures it is registered once for the lifetime of the app.

Note

The button id="accessibilityToggleBtn" must be unique on the page. Do not duplicate it.
